## Section 4: Why Devora?

**Headline:** Why Devora?

**Subheadline:** Purpose-built for CECS Students

Comparison vs alternatives (Devora checkmark vs alternative X):

**GitHub**
- Devora: Find people + career niche
- GitHub: Code hosting only (not people discovery)

**LinkedIn**
- Devora: CECS-specific + skill-aligned + student-first
- LinkedIn: Professional/formal, generic audience

**Discord/Slack**
- Devora: Discover your group first
- Discord/Slack: For existing groups only
